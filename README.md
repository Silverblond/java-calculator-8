# java-calculator-precourse

## 프로젝트 개요
- 주제 : 문자열을 입력받아 특정 규칙에 따라 숫자를 분리하고 계산하는 계산기 구현
- 이름 : 김동균
- 일시 : 2025-10-19


## 입출력 요구 사항
- 입력 : `구분자`와 `양수`로 구성된 **문자열**
- 출력 : 덧셈 결과
- 예외 사항 : 숫자 이외의 값 혹은 음수 입력 시 `IllegalArgumentException` 발생


## 구현할 기능 목록
1. 기본적인 덧셈 기능
- [x] 문자열 입력 받기
- [x] 빈 문자열 또는 null 입력 시 0 반환
- [x] 숫자 하나만 있는 경우 해당 숫자 반환
- [x] 쉼표(,), 콜론(:)을 구분자로 사용하여 문자열을 분리
- [x] 두 개 이상의 숫자가 있는 경우 모두 더한 값 반환

2. 커스텀 구분자 기능
- [x] `"//[커스텀 구분자]\n"` 형식의 문자열을 입력받아 커스텀 구분자 사용 
- [x] 커스텀 구분자를 사용하여 숫자들을 분리하고 더한 값 반환

3. 예외 처리 기능
- [x] 숫자 이외의 값이 포함된 경우 `IllegalArgumentException` 발생후 종료
- [x] 음수가 포함된 경우 `IllegalArgumentException` 발생후 종료


## 코드 진행 흐름
1. 입력 문자열이 빈 문자열 또는 null인지 확인
2. 커스텀 구분자가 있는지 확인
3. 구분자에 따라 문자열을 분리
4. 분리된 문자열을 숫자로 변환하며 예외 처리
5. 숫자들을 모두 더한 값을 반환


## 프로그래밍 요구 사항
- JDK 21 버전에서 실행 가능해야 한다.
- 프로그램 실행의 시작점은 Application의 main()이다.
- build.gradle 파일은 변경할 수 없으며, 제공된 라이브러리 이외의 외부 라이브러리는 사용하지 않는다.
- 프로그램 종료 시 System.exit()를 호출하지 않는다.
- 프로그래밍 요구 사항에서 달리 명시하지 않는 한 파일, 패키지 등의 이름을 바꾸거나 이동하지 않는다.
- 자바 코드 컨벤션을 지키면서 프로그래밍한다.
- 기본적으로 [Java Style Guide](https://gist.github.com/stephenparish/9941e89d80e2bc58a153)를 원칙으로 한다.


## 커밋 메시지 작성 규칙
1.  **type**
```angular2html
feat: 새로운 기능을 추가했을 때

fix: 버그를 수정했을 때

refactor: 기능 변경 없이 코드 구조를 개선했을 때 (리팩토링)

style: 코드 의미에 영향을 주지 않는 스타일 변경 (세미콜론, 들여쓰기 등)

docs: 문서를 수정했을 때 (README.md 등)

test: 테스트 코드를 추가하거나 수정했을 때

chore: 빌드, 패키지 매니저 설정 등 기타 자잘한 작업
```

2. **scope**
- 어디를 변경했는지 범위를 나타낸다. 코드의 특정 부분을 명시하여 이해를 돕는다.
- 예시: feat(login): ..., fix(api): ..., refactor(profile): ...

3.  **subject**
- 무엇을 변경했는지 요약해서 설명한다.
- 명령문으로 작성한다. (예: add login button, fix user bug)
- ~를 추가함 (X), ~가 추가됨 (X) -> ~를 추가 (O)
- 첫 글자는 소문자로 시작한다.
- 문장 끝에 마침표(.)를 찍지 않는다.
- 간결하게 50자 이내로 작성한다.
